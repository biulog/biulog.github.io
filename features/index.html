BiuLog 功能總覽

半夜餵奶、與家人交接、陪寶寶聽故事，都有順手的方式。

BiuLog 團隊 · 更新 2026-11-16

選你想了解的功能

寶寶作息與記錄 家庭共享與交接 成長手冊與家庭健康 有聲繪本、兒歌與動物互動 安撫聲音與定時播放 爸媽圈、聊天室與開發者私訊 托育機構與聯絡簿 多寶寶、備份與雲端

BiuLog 是 iPhone 和 Android 的寶寶紀錄 App，能記餵奶、睡眠、尿布與副食品，讓家人共用照顧紀錄。也有親子有聲繪本、安撫聲音，以及讓爸媽分享日常和交流育兒經驗的社群。

寶寶作息能記哪些？

首頁可快速記餵奶、睡眠、尿布和副食品。親餵可以分左右側計時，瓶餵可分開記母乳與配方奶的奶量，尿布分尿尿、便便和兩者都有，副食品可記食材、份量和備註。短按快速新增，長按可補登。

用時間線回看每一餐和每段睡眠，再從每週統計與趨勢看出作息變化。常用按鈕的文字、圖示、顏色或圖片可自己調整，也能設定提醒間隔與夜間安靜時段。看日常記錄操作

爸媽用不同手機，可以共同記錄寶寶嗎？

可以。家庭共享支援 iPhone 和 Android，建立分享後可邀請家人，大家用自己的帳號查看與新增同一個寶寶的照顧紀錄。上一餐喝了幾毫升、什麼時候換尿布，接手的人打開就能查。

看家庭共享設定與條件 · 看照顧交接清單

成長手冊能記什麼？

成長手冊可集中記身高、體重、頭圍與參考曲線，記下翻身、爬行、走路等第一次，也能用牙位圖記乳牙萌出日期。疫苗紀錄可按地區查看參考時程、已接種日期和下一劑。

家庭健康可整理健檢、就醫、症狀、體溫、用藥和食材反應。成長手冊也包含發展檢核、如廁練習和文字家庭日記。看成長里程碑記法

有聲繪本、兒歌與動物互動

BiuLog 魔法圖書館收錄大量繪本，包括有聲故事、兒歌音樂書和互動動物探索。可以一起聽《三隻小豬》、唱《拔蘿蔔》和《小星星》，也可以點選農場、森林、野生動物或恐龍來探索聲音。各本提供的語言依書籍而異。

看魔法圖書館的畫面與書單

BiuLog 有寶寶安撫音樂或環境音嗎？

有。App 裡的「安撫聲音」可播放輕柔雨聲、潺潺溪流、海邊浪聲、壁爐柴火、森林夜晚、微風樹葉與規律心跳。可調音量、持續播放，或設定時間自動停止。

在爸媽聊天室 → 更多 → 安撫聲音選一段聲音，就能播放並回到聊天。離開聊天室後也可以繼續播放。想和寶寶一起唱歌時，可以打開魔法圖書館的兒歌音樂書。

爸媽圈和爸媽聊天室各能做什麼？

聊天室有中文、日本語與 Global 分區，適合即時交流。BiuLog 爸媽圈可以發貼文、留言，分享寶寶日常、穿搭和育兒用品心得，也能刊登贈送或二手出售資訊。爸媽圈適用 BiuLog 3.3.5 或更新版本。

有 App 操作問題或想提功能建議，可以在爸媽聊天室選「私訊 BiuLog」直接聯絡開發者。看爸媽圈入口與發文方式

怎麼查托育機構的公開紀錄？

選托嬰中心或幼兒園前，可從爸媽聊天室 → 機構查詢，依機構名稱、縣市與類型查閱台灣官方公開裁罰紀錄。日本可查看已收錄的公開監查、指導資料與地方公告。點開官方來源和處分日期，參觀前就能先做好功課。看 App 的查詢步驟與官方入口

加入 BiuLog 合作機構的家庭，還能在 App 查看自己寶寶的聯絡簿、每日照護紀錄、公告、照片和留言。了解機構聯絡簿

能分開記多位寶寶，也能備份嗎？

每位寶寶可有自己的資料、紀錄與首頁配置。基本記錄可先在手機上開始，之後可匯出 CSV 或使用 JSON 備份及還原。登入後可把日常、成長、里程碑和疫苗記錄保存在個人雲端。照片、自訂按鈕與偏好設定可透過完整 JSON 備份保存。
