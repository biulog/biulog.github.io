BiuLog OpenSEO Local 隱私權說明

生效日期：2026 年 10 月 11 日。此說明適用於 BiuLog 經營者自用的本機 OpenSEO 與 Google Search Console 連接，不適用於 BiuLog 育兒 App。

讀取的資料

經帳戶擁有者同意後，本工具取得 Google 基本帳戶識別資料（帳戶識別碼、電子郵件及基本個人資料）、OAuth 授權憑證、可存取的 Search Console 資源清單，以及所選資源的搜尋成效與網址索引資料。搜尋成效可能包含搜尋字詞、網頁、點擊、曝光、排名、日期、國家和裝置分類。

目前要求的權限為 openid、email、profile 與 https://www.googleapis.com/auth/webmasters.readonly。本工具不要求修改 Search Console、讀取 Gmail、Google Drive 或 Google Ads 的權限，不讀取 BiuLog 育兒 App 的家庭或寶寶資料。

使用目的與分享

資料只用於向擁有者顯示網站搜尋表現、檢查索引問題及依其指示改善網站。Google 處理登入、授權及 Search Console API 請求；本機 OpenSEO 處理並顯示返回結果。擁有者主動要求 Codex 協助分析時，選取的報表內容會提供給該分析工具處理，不將 OAuth 憑證加入分析內容。

不出售 Google 使用者資料，不將其提供給廣告商或資料仲介，也不將其用於廣告個人化或訓練通用 AI 模型。未經另行授權，不將搜尋資料送往額外的資料供應商或 AI API。本工具對 Google API 所得資訊的使用及傳輸遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保存與保護

連接資訊、設定與分析資料由擁有者在自己的電腦保存；Google 授權 token 由 OpenSEO 加密保存，解密金鑰存於受本機檔案權限保護且不提交版本庫的設定檔。分析工具僅綁定本機介面。依擁有者要求匯出的報告可能保存在行銷工作目錄；只有擁有者授權的人員或工具可存取。此公開說明頁不包含私人搜尋報表或登入憑證。

本說明頁未植入分析或廣告追蹤程式；靜態網站代管商 GitHub Pages 可能依其服務政策處理網站請求紀錄。

撤回授權與刪除

擁有者可在 Google 帳戶的第三方連接撤回本工具授權，停止後續 Google 資料存取。也可在 OpenSEO 移除已連接帳戶，清除本機帳戶連接及保存的授權；僅中斷某個專案的連接不一定會移除帳戶授權。已匯出的報告與備份需由擁有者另外刪除，撤回授權不會自動刪除這些副本。

本機資料在持續使用期間保留，擁有者可隨時移除連接、報告及備份。若有資料處理或刪除問題，請聯絡 hao10d@gmail.com。

變更

如未來擴充用途、權限或資料接收方，會先更新此說明並取得適用的授權。本頁日期記錄最近一次更新。
